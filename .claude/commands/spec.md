Read `$ARGUMENTS` as a source reference or requirement text. Use direct prompt/local-file intake without requiring a tracker. If it identifies an external system, verify the connector is enabled and fetch it with bounded provenance; do not fabricate unavailable results.

Capture work ID, goal, acceptance criteria, affected projects, source references/revisions and requested delivery. Retain external issue IDs separately.
