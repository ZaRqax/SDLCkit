# pi compatibility

The retained `setup.sh pi` path and `port-agents.py [OUT_DIR]` generate pi-subagents from neutral canonical roles using stable legacy aliases. The session's selected model is inherited; active model providers and MCP servers are empty by default. Existing optional package versions remain declared in settings and must be reviewed/installed explicitly when needed. No package installation is implied by rendering.

Use the target project's AGENTS.md, actual commands and requested delivery. The legacy `/run`/`chain` experience remains a harness feature; generic runbooks live in `.claude/commands/`. For isolated code workers use the explicit runtime, not shared-tree pi background edits. Optional v1 selfhosted presets are preserved in `profiles/local-model/`. See `docs/compatibility.md`.
